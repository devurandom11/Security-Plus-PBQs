Twelve exam-style simulations

Each exercise below is a self-contained performance based question modeled on the CompTIA Security+ SY0-701 exam. You work a realistic scenario at the fictional Northwind organization: read the briefing and exhibits, fill in the scored fields, then submit for a score with per-item feedback.

  • Highlighted yellow fields are scored; gray fields are already configured for you.
  • Each exercise allows three attempts and shows a score with feedback when you submit.
  • Nothing is installed and nothing is sent to a server — every exercise is a single HTML file that runs in your browser.

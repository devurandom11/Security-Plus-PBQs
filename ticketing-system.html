Scenario

Briefing and classification rules for the Northwind help desk ticket triage exercise.

You are the Tier 2 help desk lead at Northwind. Four open tickets describe suspected social engineering. Each one shows the user's own words and a short Tier 1 note summarizing the evidence that was collected. Classify every ticket so the incident response team can act on it.

Classification rules

  1. Diagnosis. The most specific attack type the evidence supports, not the general category. When the lure arrives by SMS text message or voice call, name the attack type for that channel. Most of these attacks use an invented story, so a pretext by itself does not decide the diagnosis.
  2. Tactic. The social engineering principle the attacker relied on to get the user to act. If the user hesitated, choose the principle the attacker used to overcome that hesitation.
  3. Mitigation. The single control most specifically aimed at the weakness the evidence shows. Every ticket would benefit from awareness training, so choose the technical or procedural control that fits the evidence.
